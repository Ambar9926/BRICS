# BRICS Infrastructure Demand AI

A Digital Public Infrastructure (DPI) platform for 3.5 billion citizens across BRICS nations, connecting citizen reports directly to AI-driven government budget allocation and spatial planning.

Built for Track 1: AI for Infrastructure — Google Built with AI Hackathon.

## 🚀 Links
- **Live Demo:** https://brics-infrastructure.bolt.host
- **Demo Video:** https://youtu.be/7MbAB2eSWR0

## ✨ Key Features
- **Citizen Portal:** Gemini Vision AI photo damage assessment, 6-language voice notes, BRICS AI chat assistant, community upvoting, and ticket tracking.
- **Government Response Portal:** Real-time impact metrics, category breakdowns, and team assignment tracking.
- **GIS Heatmap:** Spatial demand intelligence with regional drawing tools across 5 BRICS nations.
- **Policy Simulator:** Gemini Flash powered AI Smart Budget Allocator ($100M - $5B slider).
- **Predictive Alerts:** Early infrastructure failure forecasts with probability scoring.
- **Admin Panel:** Triple-layer security (Email + Password + 40-character Security Access Code).

## 🛠️ Tech Stack
- **Frontend:** React, Tailwind CSS, Lucide Icons
- **Backend & Auth:** Bolt Database
- **AI Models:** Google Gemini Vision API & Google Gemini Flash API
- **Platform:** Built with Bolt.new
